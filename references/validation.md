# 验证与排障

[English](validation.en.md)

按用户选定功能验收，不要求每个实现包含所有扩展。每项结论带证据层级：文件已写入、命令已通过、Desktop 已加载、真实状态已识别、手机已收到。

## 最小验收路线

1. 用合成事件验证分类、去重、恢复和内容裁剪。
2. 用实际 shell 执行安装后的钩子命令，验证退出码、stdout、中文／空格／特殊字符路径，以及后台助手存活。
3. 在用户方便时真正退出并从正常入口重开 Desktop，完成所需钩子信任；验证首次事件启动且只有一个监控。至少覆盖两种本机实际存在的入口，进程级方案还测无钩子时的启动。
4. 触发一次所选正常状态，核对队列、桥接接受和手机收到的内容；报错、中断和等待分别按所选范围验证。
5. 测退出时仍有待发消息、短暂断网和再次启动；结果必须符合用户选择的退出／补发策略。
6. 需要账号切换兼容时，按原切换流程分别重启验收；不为测试擅自更换账号或破坏正在运行的任务。

当前窗口内手动调用钩子，不等于真实 Desktop 冷启动。配置文件正确，也不等于旧进程已经重新加载或钩子已获信任。

## 必须覆盖的易错边界

| 范围 | 有意义的测试 |
| --- | --- |
| 启动 | 进程暂不可见、半写元数据、多钩子同时唤醒、已有但未就绪、CLI／子代理、配置缺失、助手退出后锁释放 |
| 进程身份 | PID 被其他进程复用、旧状态缺少身份版本、旧“接口已启动”日志但服务已退出；确认会重新启动而不是误判在线 |
| 状态 | 并发 Stop 续跑、新活动取消候选、暂时 503 后成功、最终失败、完成与中断不同顺序、晚到旧轮次、长时安静 |
| 等待 | 相同请求重复、响应后恢复、已解决但尚未发送、新请求 |
| 退出 | 主程序退出、辅助服务重启、多窗口、维护标记到期、退出后末尾追加、重新打开 |
| 持久化 | 半行、替换、截断、路径别名、通知溢出、睡眠恢复、游标／状态／入队之间崩溃 |
| 投递 | 未就绪、超时、限流、认证失效、接受后记账前崩溃、积压恢复、目标变更、共享实例不被停止 |
| 内容 | 合成秘密、路径、长内容、引号／换行、标题变化不触发重复 |
| 资源 | 合成长回复、大量已结束轮次、长时间空闲；确认活动证据有界、终态释放正文，CPU／内存按实测记录 |
| 入站（若选） | 选定目标、重名标题、过期映射、忙碌任务、越权与重复消息、真正续跑原任务 |

多顺序测试用于验证真实竞争，不是检查实现中有没有某个函数名。隐私测试使用合成值；资源测试看空闲 CPU、读取字节、启动延迟和队列年龄，不用没有测量的“零占用”。

## 定向排障

| 现象 | 先找证据 | 修复后的验收 |
| --- | --- | --- |
| 钩子 `exit code 1`，没有自己的日志 | 实际命令解释器、语法、路径、导入及 stdin 解码 | 用相同执行方式重现，再跑 SessionStart／Stop |
| `SessionEnd` 提示异步仍被同步运行，或退出码为 1 | 该事件始终同步、超时很短，且命令是否做了联网／常驻／重任务 | 把重任务移到支持异步的事件；`SessionEnd` 只做快速本地收尾，再做真实退出验收 |
| 写了 hooks 但没有调用 | 生效层、信任、进程是否加载新定义 | 真实触发，而不是仅看文件 |
| 进程存在但不发 | 当前进程身份、接口就绪、队列时间和错误 | 同一实例实际连接与合成发送 |
| `doctor` 显示在线但钩子不再拉起 | 状态文件中的身份版本、可执行文件、创建时间；最近启动日志不能单独作为证据 | PID 复用夹具中被识别为失效，并由下一次有效钩子自恢复 |
| 重启后成批到达 | 发送器存活区间、退避、退出策略 | 按约定的补发时机验收 |
| 一件事发很多遍 | 当前轮次、终态键、账本、投递不确定窗口 | 重放同一事件与重启不新增本地通知 |
| 更新后不认识事件 | 版本与最小字段差异 | 更新适配器后验证受影响状态 |

先定位再修复。只为会自然重复出现的条件加自动恢复；一次配置错误修好即可，不增加持续全量扫描。消息桥坏了时健康提醒也可能发不出去，本地诊断入口必须可用。

## 实测记录的限度

| 参考环境 | 已有证据 | 不能据此声称 |
| --- | --- | --- |
| Windows，Codex 核心 0.159.2，CC Connect 1.5.0 | 本地参考实现的启动／状态／队列回归测试，以及 PowerShell 钩子命令实测 | 仓库包含该程序，或所有系统与版本已兼容 |
| Windows，CC Connect 1.5.0 | 历史 QQ 真实投递、本地套接字路径故障及缩短路径验证 | 路径存在就可用，或存在一个适用于所有运行时的固定长度上限 |
| 钩子命令已修正的部署 | 命令层验证可以完成 | 未执行的 Desktop 重新加载、信任和冷启动也已通过 |

这些是经验来源，不是可下载成品的兼容性认证；本仓库没有运行程序或其全套测试夹具。

## 维护与交付

提供本地状态／诊断、定向重试、暂停／恢复、更新与卸载入口，形式按产品选择。日志和队列有有限保留，不无限备份。升级时重测变化触及的解析、钩子执行、启动与投递路径，不为每条通知重新盘点整个系统。

最终说明哪些功能已验证、哪些暂不支持、哪些需用户完成绑定／重启，以及失败时从哪里恢复。文档校验脚本只检查结构、本地链接、双语参考覆盖和有限隐私模式；不证明翻译语义、外部链接、钩子协议或运行行为。
