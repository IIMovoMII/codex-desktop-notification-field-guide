# 隐私与数据边界

[English](privacy.en.md)

状态判断可以在本地完成；提醒离开本机前，明确用户选择了哪些内容。

## 内容选择

| 内容 | 建议起点 |
| --- | --- |
| 状态、发生时间、稳定通知别名 | 可以发送 |
| 任务标题、模型名称 | 按用户选择；标题也可能含隐私 |
| 限长回复摘录 | 用户选择后再处理，先脱敏 |
| 原始提示、工具输入输出、整段错误／历史 | 不作为普通提醒内容 |
| 通讯平台凭据与接收人真实编号 | 留在受限的本地配置 |
| Codex OAuth／API 凭据 | 提醒程序无需读取或管理 |

回复摘录是通知内容选项，不必再调用模型生成；入站继续任务则属于另一条数据流，另行说明范围。

## 最小事件与日志

钩子默认只留下任务／轮次关联、事件、时间和必要状态字段。读取 JSONL 时可能不可避免地把含正文的一行短暂解码进内存，不能宣传“正文从不进入内存”；解析后及时丢弃不需要的字段，不存入普通状态、日志或发送队列。

分类尽量只用结构字段。必须处理错误文本时，先去除认证头、令牌、网址查询与签名片段，替换个人路径和身份，限制长度、清理控制字符。正则脱敏不能证明绝无秘密，最小收集更可靠。

游标可能需要真实路径和任务 ID，这些仅限本机。运行日志用类别、耗时和不直接暴露身份的关联值；已发送账本只保留去重所需信息。队列中的摘要仍可能敏感，要限制权限与保留期。

## 安装、迁移与卸载

通知配置与 Codex 登录档案分开；切换账号时不用复制机器人凭据。只补丁式添加自己的钩子，更新和卸载也只改自己拥有的条目。

恢复材料按用户选择保留，通常一份已知良好副本或字段级回滚记录即可，不无限堆积。卸载时先停止自己的组件、撤销自己的自动入口，再让用户选择保留还是删除本地队列与绑定；共享桥接和 Codex 历史不在删除范围。

## 公开材料

公开夹具从零构造，不复制真实会话再换名字。仓库只保留结构、方法和合成案例；版本与可复现步骤可以公开，真实配置、认证、收件人、机器路径和消息正文不能随文档上传。自动扫描只是有限筛查，发布前仍需看差异。
